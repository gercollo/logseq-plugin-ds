# Development workflow

- Work on a topic branch and open a pull request against this fork.
- Keep cleanup, design proposals and feature implementations separately reviewable.
- Do not push changes directly to `main`. Merge or publish only when explicitly requested.
- Run `pnpm lint`, `pnpm test` and `pnpm build` for runtime changes.
- Keep documentation in English and examples focused on OpenAI-compatible interfaces.
- Preserve copyright attribution and never commit credentials or generated inference results.
